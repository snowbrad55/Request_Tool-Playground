<h1 align="center">Typhoon Mission Support Centre Requests Tool</h>
<hr>


## Situation: 
Across the Ty MSC there is a number of disparate systems used to record and track taskings with no centralised means to co-ordinate or easily share corporate knowledge. solutions have been sought using both the Power Platform suite and Teams options. however each have limitations. 

## Task: 
IxTS is tasked with developing a requesting tool that is intuitive to the lay customer as well as specialists employed at the Ty MSC. Building upon a university project from a former team member, the application seeks to consolidate the numerous methods used to record and track tasks.

## Action: 
This application is a .Net, Server Side Rendered, Blazor application exploiting the MudBlazor framework over Bootstrap. Developed initially for SQL Server, but updated to deploy code-first design to PostgreSQL servers. Using EF Core frameworks, if required the code can be easily manipulated to operated with SQL Server with minimal adjustments.
